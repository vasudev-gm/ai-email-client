# AI Email Client

An AI-first universal email client built as a mobile-ready Progressive Web App (PWA). Supports Gmail, Office 365, and IMAP (Yahoo, AOL) with a unified inbox, AI-powered summaries, reply drafts, and email prioritization.

## Features

- **Unified Inbox** — aggregate emails from Gmail, Outlook/Exchange, and IMAP accounts
- **Account Switching** — seamlessly switch between multiple email accounts
- **AI Summaries** — 2-3 sentence email summaries powered by AI
- **AI Reply Drafts** — professional reply suggestions generated by AI
- **AI Prioritization** — 1–5 urgency scoring for every email
- **Multi-Provider AI** — supports Anthropic Claude, OpenAI, or local fallback
- **Compose / Reply / Forward** — full email composition with rich toolbar
- **Search** — full-text search across all emails
- **Labels** — custom color-coded labels
- **Archive & Delete** — standard inbox management
- **PWA** — installable on mobile and desktop, works offline

## Tech Stack

| Layer | Technology |
| ----- | ---------- |
| Framework | Next.js 15 (App Router, TypeScript) |
| Styling | Tailwind CSS |
| Auth | NextAuth.js v5 (Google, Microsoft, IMAP credentials) |
| Database | Prisma + SQLite (dev) / PostgreSQL (prod) |
| AI | Multi-provider: Anthropic Claude, OpenAI, or local fallback |
| State | Zustand + TanStack React Query |
| Testing | Jest + React Testing Library |

## Getting Started

```bash
# 1. Clone and install
npm install

# 2. Configure environment
cp .env.example .env
# Edit .env — set ANTHROPIC_API_KEY or OPENAI_API_KEY for AI features
# Or leave empty to use local fallback

# 3. Initialize database
npx prisma db push

# 4. Start dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Environment Variables

| Variable | Required | Description |
| ----- | ---------- | ------------- |
| `DATABASE_URL` | Yes | SQLite: `file:./dev.db` or PostgreSQL URL |
| `NEXTAUTH_SECRET` | Yes | Random string for session encryption |
| **AI Provider** (choose one or none) | | |
| `ANTHROPIC_API_KEY` | No | Anthropic Claude API key (recommended) |
| `OPENAI_API_KEY` | No | OpenAI API key (alternative) |
| `OPENAI_MODEL` | No | OpenAI model: gpt-5.4-nano, gpt-5.5, gpt-5.4-mini (default: gpt-5.4-nano) |
| **Email OAuth** | | |
| `GOOGLE_CLIENT_ID` | No | Google OAuth — required for Gmail accounts |
| `GOOGLE_CLIENT_SECRET` | No | Google OAuth secret |
| `MICROSOFT_CLIENT_ID` | No | Microsoft OAuth — required for Outlook accounts |
| `MICROSOFT_CLIENT_SECRET` | No | Microsoft OAuth secret |

**AI Provider Priority**: The system automatically selects the first available provider:

1. Anthropic Claude (if `ANTHROPIC_API_KEY` is set)
2. OpenAI (if `OPENAI_API_KEY` is set)
3. Local fallback modes:
   - Keyword heuristics (always available)
   - True local SLM (`@xenova/transformers`, model downloaded on first use with progress UI)

```bash

```

Set the environment variables in the Vercel dashboard. Switch `DATABASE_URL` to a PostgreSQL connection string (e.g. Neon, Supabase) for production.
